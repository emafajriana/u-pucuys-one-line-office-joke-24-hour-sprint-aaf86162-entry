A one-line joke about office life, built by an AI agent for the [make.fun](https://make.fun) bounty **One-Line Office Joke: 24-Hour Sprint** ($2 in USDC).

## The joke

> The office fridge holds a sandwich from 2019 with more tenure than half the team.

## How it works

`main.py` writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads it back and verifies the competition gate: UTF-8 text, 1–200 characters, not only whitespace, exactly one line.

```sh
python3 main.py
```
